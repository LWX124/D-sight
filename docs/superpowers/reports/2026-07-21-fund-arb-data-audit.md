## 数据获取过程总结

### 已完成的工作

1. **基金种子数据导入**
   - 92 个基金的基础信息（代码、名称、跟踪标的、估值方法等）
   - 数据来源：手工整理 + 东方财富

2. **净值历史数据导入**
   - 使用 curl + 天天基金网 API（绕过 httpx 网络问题）
   - 1,932 条净值记录
   - 覆盖所有 92 个基金

3. **跟踪标的历史数据获取**
   - 使用 akshare 获取：
     - 美股历史价格：14 个符号，每个 70 天
     - A股指数历史：15 个符号，每个 70 天
     - 国内期货：1 个符号（白银）
   - 总计 2,442 条历史记录

4. **汇率数据获取**
   - 使用 curl + 中国外汇交易中心 API
   - USD/CNY, HKD/CNY, JPY/CNY 中间价
   - 15 个工作日的历史数据

5. **实时行情获取**
   - 修改 SinaQuoteFetcher 使用 subprocess + curl（解决 httpx 网络问题）
   - 配置修改：fund_arb_backend 从 "fake" 改为 "sina"
   - 90 个基金的实时价格

6. **估值计算与快照生成**
   - 61 个基金成功计算估值和溢价率
   - 收盘数据已保存到数据库

### 遇到的问题及解决方案

#### 1. httpx 网络连接失败
**问题**: Python httpx 库无法连接外部 API，超时或连接被拒绝  
**原因**: 本地网络环境问题（可能是防火墙、VPN、DNS）  
**解决**: 
- 修改 `SinaQuoteFetcher` 使用 `subprocess.run(['curl', ...])`
- 所有数据获取脚本改用 curl 或 akshare（akshare 内部使用 requests）

#### 2. 新浪历史接口不可用
**问题**: 新浪历史 K 线 API 返回 null  
**解决**: 使用 akshare 替代，成功获取所有主流标的的历史数据

#### 3. 汇率中间价数据不足
**问题**: 初次只获取了今日汇率，导致大部分 QDII 基金无法估值  
**解决**: 
- 补充获取中国外汇交易中心的历史中间价
- 但该 API 仅返回最近 15 个工作日数据
- **遗留问题**: 净值日期早于 15 个工作日的 QDII 基金仍无法估值

#### 4. 部分 A股新指数无法获取
**问题**: sh930xxx 系列新指数，akshare 返回数据格式错误  
**解决**: 暂时跳过，影响约 12 个基金

#### 5. 港股指数连接超时
**问题**: 东方财富港股指数 API 连接异常  
**解决**: 暂时跳过，影响约 2-3 个基金
